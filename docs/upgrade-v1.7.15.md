## 合并与适配

- 保存升级前全部定制源码；20 个 Git 冲突逐段解决。
- 官方将生成参数和模型能力拆至 `generation`、`modelcatalog`，Atlas 的分辨率、参考数量、时长、报价参数同步迁入。
- 保留系列分类、热门与可用性排序、所有模态报价、右键复制、节点图片/视频镜像、多角度与打光图片预览、画布平滑缩放。

- 保留外部 Python MCP 的 11 项工具，并适配新版业务 owner 授权；凭据只在本机桥接中使用，工具输出继续脱敏。

- 实际工作区首次启动发现旧 Atlas 插件使用 `user` 来源标记，新版严格校验拒绝导入。补丁提交 59f2ff8 仅在遗留文件导入时将其映射为 `uploaded`，保留包、哈希、启用状态，仍严格校验新权威记录。合成回归覆盖导入及重启，完整 `plugins` 套件通过。
