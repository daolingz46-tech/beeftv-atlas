# 视频提交与结果恢复

视频提交、上游生成、结果下载分别展示状态，不能用本地等待超时推断上游任务失败。

- 已取得上游任务 ID：已安装的声明式协议如果能构建 GET 状态查询，可在执行窗口超时后继续后台查询原 ID，每次恢复不会再次调用创建接口。自动恢复最长持续到任务开始后的 24 小时；明确的上游失败、取消和不支持安全查询的协议仍正常结束。
- 未取得上游任务 ID：524、连接断开或回执解析失败可能发生在受理之后。节点显示“待确认”，保留原任务和诊断信息，禁止自动重发。此时没有可查询 ID，不能显示正在自动核对或承诺结果会自动返回。需核对供应商记录；本地任务 ID 不等于供应商 prediction ID。
- 明确未受理或明确失败：仍展示原错误，不用动态等待掩盖拒绝。
- 正在等待的任务显示动态进度条；只有供应商提供进度时才显示百分比。停止的任务不显示运行中的动画。

Atlas 的公开查询协议为按 prediction ID 查询。提交回执丢失且没有该 ID 时，不能单凭 524 判断是否扣费，也不能靠重复创建来找回结果。要实现这类请求的完全自动恢复，需要供应商提供可验证的幂等键查询、任务检索或可达的回调通道。

验证范围：模拟上游下的原任务恢复、丢失回执不重发、下载恢复、取消与查询协议保护，以及前端进度展示测试。测试不提交真实收费生成任务。
