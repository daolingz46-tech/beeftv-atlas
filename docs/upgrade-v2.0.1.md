# v2.0.1 定制版升级验证

## 版本与合并

- 原官方基线：v1.7.15；原定制修复保存于 `3bab946`。
- 目标官方稳定版：v2.0.1，标签提交 `5ae8e627508f0e77108c3f9b6526fcfa4faaf7a5`。
- 在独立工作目录先合并 v2.0.0，再合并 v2.0.1；候选集成提交分别为 `5f164f5`、`f43d644`。
- 两次合并分别处理 23 个和 5 个文本冲突。正式应用只在构建、关键回归与数据副本迁移验证后替换。

## 保留与适配

- Atlas 费用预估、尺寸与分辨率适配、参考素材能力和原任务查询恢复。
- 模型菜单的可用性与系列排序；默认模型设置的渠道、系列筛选和选择持久化。新增加的多模态默认模型也使用此筛选。
- 媒体剪贴板复制、批量复制、镜像、Alt 拖动复制、小地图预览及文本放大阅读。
- 新版将生成配置和进度展示拆到共享模块，定制参数和提交状态展示随之迁移；避免保留两套提交配置构造逻辑。
- 合并新版工作流拖放与 Alt 复制：复制手势不提交工作流节点放入操作；普通拖动保留新版目标识别。
- 助手保留明确的渠道余额与权限错误，同时继续隐藏未知供应商错误中的地址和请求细节。随包清单包含这些本地模块。
- 原生系统拖出功能继续撤回，不重新加入系统拖拽接管。

## 验证结果

- 前端 TypeScript 检查、完整媒体资源 Vite 构建通过。
- 11 个专项测试文件共 77 项通过，覆盖模型能力与系列、默认模型、剪贴板、镜像、小地图、文本、画布不可用和进度显示。
- 后端桌面端、CLI、生成、协议、模型目录、出站请求、数据库、工作区及插件包测试通过。
- app 专项回归覆盖 Cost、Quote、VideoRecovery、Declarative、Resumable、DBRuntime、TaskScope 和 Atlas，运行通过。
- 官方 Durable 会话与模型切换、崩溃恢复、停止、历史和渠道错误回归通过。随包 Node 24.15.0 与钉选的官方 SDK 1.2.0 一起检查导入。
- 官方协议插件包共 86 个；FFmpeg/FFprobe 随包版本、哈希、实际转码与媒体探测检查通过。
- 当前数据的独立 SQLite 副本连续迁移到 schema 25，完整性检查通过；8 个画布、50 条任务、441 个素材记录保持一致，原有画布字段校验值不变。迁移检查不启动任务 worker。
- 正式程序已实际打开，原项目可读取；MCP 初始化和只读项目列表调用成功，发现 214 个工具。没有进行真实付费生成。

初次 `go test ./...` 并未全绿：当时候选目录尚无构建后的官方插件包，另有 Windows 文件权限断言、未关闭临时 SQLite 文件清理及环境投影检查失败。补齐插件后的上述关键包和功能回归通过；没有把这些结果表述为全量测试通过。

原生链接阶段仍输出 `multiple non-default manifests` 提示，但构建返回成功，正式客户端启动及只读工作区访问已验证。逐项 GUI 操作与真实收费模型不属于本次已完成的自动验收。

## 数据保护和回退

更新前正常关闭应用，再使用 SQLite backup API 保存一致副本并运行 integrity_check，同时备份工作区密钥、模型配置、插件注册表、客户端登记、助手历史、旧程序、CLI 和 sidecar。更新没有删除原素材目录。

本机回退备份标记为 `before-v2.0.1-20261022-190237`，包含数据计数与程序组件；不能只换回旧 exe 而继续使用新版迁移后的数据库。回退应配套恢复旧程序、sidecar、数据库及其工作区密钥，并先保留升级后新增的数据。

本次为本机定制版升级，没有向作者仓库推送或发布安装包。其他 Agent 已运行的旧 MCP 进程需要重新连接，才能使用新程序与最新工具目录。
