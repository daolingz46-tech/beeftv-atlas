# 画布、图片报价与复制修复记录

## 原因与修复

- 图片报价的参考图片探测接口不接受 data URL，改为上传同尺寸的空白 PNG 并缓存公共地址。仅报价使用空白图，生成仍使用原参考素材。
- 部分 Atlas 图片接口要求 `宽*高`。共享尺寸转换保留能力配置指定的格式，生成与报价复用同一转换；OpenAI 的 `宽x高` 和比例参数保持原合同。已根据官方模型定义修正本地 6 个 Qwen 图片模型的能力默认尺寸。
- 老画布浏览器草稿和后端版本可能不同，缺少当前作用域的确认记录。只从授权的画布历史找回可信基线，再做三方合并；实际冲突继续阻止提交，提供保留副本或读取最新版本。比较忽略 JSON 对象键顺序，保存状态不再把缓存成功显示为后端保存成功。
- 设置中的渠道、系列筛选在选择时按用户作用域保存，切换项目与重新打开后可恢复。实际默认渠道在选择具体模型时生效；筛选与现有默认模型不同会提示当前默认渠道，避免以为改了筛选就改了请求渠道。
- Alt 拖拽使用 DOM 预览，结束时一次创建副本，复用节点复制逻辑与撤销历史。取消、失焦、无位移不复制。
- 框选后右键可以复制所有选中图片、视频文件。桌面桥先检查每份资源归属并准备文件，再一次写入 Windows 文件剪贴板；相同资源的多份节点使用独立文件名，不丢失重复项。失败不会写入部分选择。
- 小地图旧代码在超过 24 张图片时关闭所有图片预览，也会渲染折叠批次的隐藏图片。改为最多 24 张可辨认的缩略图，隐藏节点不参与地图，较小节点用颜色和悬停名称表示，避免文字遮挡。
- 报价上游明确返回 `not found` 时显示该模型暂未提供报价，避免误报为用户参数问题。报价不可用不能推断生成一定不可用。

## 验证范围

前端类型检查、默认模型保存与筛选浏览器测试、Alt 复制与撤销浏览器测试、小地图浏览器测试、媒体保存与复制测试、画布提交日志与合并回归测试通过。后端生成包、报价重试与素材报价测试、桌面复制边界测试通过。Windows 文件剪贴板实际验证了 10 个图片路径与 1 个视频路径的数量、顺序和文件名，并恢复原剪贴板。4,834 组生成请求通过生产适配器离线检查；这不等同于在线付费生成验收。

免费在线报价抽查了 38 个不同模型，修复并补齐必需输入后 35 个成功。Youchuan v8.2 的文生图、去背景、图生视频报价接口返回 `not found`；这属于上游报价接口返回的结果，不能保证其生成接口是否可用。数字人报价必须提供图片与音频。

另发现一条实际生图任务使用 BeefTV 渠道并被上游以余额为零拒绝；这不是 Atlas Key 或画布尺寸错误。设置筛选仅用于找模型，应选择具体的 Atlas 模型后生成。

未批量提交付费生成任务，也未在微信聊天窗口执行粘贴或发送。Windows 文件剪贴板可用于接受该格式的应用，微信最终接收形式和数量受其客户端限制。

本次安装前保留程序与数据备份；有真实冲突的原画布保留，另创建恢复草稿保留全部节点与连线，不覆盖冲突原稿。数据、素材、密钥和诊断缓存未纳入源码提交。
