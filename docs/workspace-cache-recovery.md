# 桌面工作区缓存读取故障

## 现象与定位

启动后显示“工作区暂时无法加载，项目或模型配置未能完成读取”。本机 SQLite 项目与模型配置接口读取正常，但 WebView IndexedDB 的画布、素材列表记录返回 `NotReadableError: Data lost due to missing file`。整个会话初始化因缓存读取失败中断，错误页将其与模型配置故障混在一起展示。

使用关闭程序后复制的浏览器存储，在只读访问本机 API 的隔离浏览器中重现了相同错误。未清空原缓存、项目数据库或模型配置。

## 修复边界

- 仅桌面运行时允许重新读取 SQLite 对应的画布和素材列表投影；仅处理明确的 `NotReadableError`。其他存储错误仍上抛。
- 草稿、提交日志、历史、媒体及模型凭据不适用该回退，也不删除整库。
- 损坏画布缓存必须成功重新读取本机项目库后才继续启动；读取失败仍阻止打开，不能以空项目覆盖数据库。
- 页面提示本机缓存恢复，未保存的编辑仍需从本机草稿核实，不声称未保存内容已恢复。
- 创作偏好改为由会话启动显式加载，避免创建 store 尚未返回时同步访问自身 `setState`。
- 启动接口完成后清理超时计时器。

## 验证

- 17 项缓存边界、工作区启动和模型配置持久化测试通过。
- 原缓存副本可进入首页并显示已有项目；不再因不可读缓存或同步 store 初始化阻断。
- TypeScript 与前端构建通过。隔离浏览器验证不调用收费模型，不向本机业务 API 写入内容。
- 原生桌面版安装后实际窗口已进入原画布，图片、视频、连线及小地图显示正常。14 个画布、50 条任务、526 个素材记录保留；SQLite 完整性检查正常，模型配置与更新前一致。
