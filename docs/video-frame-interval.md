# 视频节点按间隔抽帧

选中视频，在「关键帧截取」菜单选择「按间隔批量抽帧」。默认每秒一张，从视频 0 秒开始，完整覆盖设定间隔内的时间点，不额外重复终点。间隔滑块和秒数输入框联动，最大值为视频时长；另有画面定位滑块、秒数输入，以及原来的首帧、当前帧、尾帧快捷操作。

确认前显示图片数量。单次最多 600 张，超过时阻止执行并提示增大间隔。抽取与图片保存顺序执行，显示已处理数量，不在内存中保留整批 PNG。结果复用原来的媒体入库和画布持久化路径，保留视频来源、毫秒时间点、原图比例和连接，按时间排列在视频右侧。切换画布会停止操作，避免向另一个画布写入结果。此功能不提交模型生成任务。

## 验证

- 抽帧时间计算、边界、数量限制、节点布局及媒体保存归属：29 项测试通过。
- 使用 FFmpeg 生成红、绿、蓝各一秒的视频，在 Chrome 中运行实际抽帧组件与解码函数：验证间隔输入、滑块上限、手动选帧、三张画面的像素颜色、逐张处理进度及释放 PNG 引用。测试夹具只替换应用数据读取，不访问用户项目。
- TypeScript 和完整前端构建通过；Windows 原生构建通过。链接器仍有此前版本已有的多个 manifest 警告，启动后窗口响应、API 和数据完整性检查通过。
- 本机安装保留原有 CLI、模型配置、插件和 Agent 运行时，只替换桌面可执行文件。关闭后备份数据库和旧程序，再安装并重开；14 个画布、50 条任务、526 个素材记录与安装前一致。
- 未逐一验证所有视频编码、超长视频或 600 张高清图片的最大负载；未调用任何付费生成模型。

可复用浏览器验证命令（在 `web/` 运行，系统须有 Chrome 和 FFmpeg，或通过 `FFMPEG_PATH` 指定 FFmpeg）：

```sh
bun scripts/test-video-frame-browser.ts
```
